# PRD - Core PMS

## Objective
Build a centralized back-office system for villa inventory, reservations, finance tracking, reporting, and role-based access for 3 brands:
- PuncakMediaBogor
- Ngevillayuk
- Kagivilla

## Main Modules
1. Master Data Property
2. Media & Gallery
3. Smart Pricing
4. Reservations & Booking Items
5. Payment Ledger
6. Finance Spreadsheet Sync
7. Security & Role Access

## Main Concepts
- Parent-child villa architecture
- Cross-listing across brands
- Dynamic pricing by day type and seasonal override
- Line-item booking structure
- Flexible payment ledger
- Guest public invoice link

## Tech Stack
- Laravel 12
- MySQL
- TailAdmin
- Blade
