# Progress 2026-04-11

## Ringkasan
Fokus hari ini adalah menstabilkan fondasi Phase 1, melengkapi modul inti PMS, menegaskan aturan UI dan Rupiah, menambah dashboard berbasis data nyata, serta menyiapkan data demo yang cukup banyak untuk testing manual.

## Selesai Hari Ini
- Menegaskan aturan bahwa dashboard harus tetap memakai TailAdmin yang sudah ada.
- Menegaskan aturan bahwa semua nominal uang memakai Rupiah integer tanpa desimal.
- Menyelesaikan flow inti Phase 1 yang aktif dipakai:
  - master data `brands`
  - master data `villas`
  - master data `villa_units`
  - master data `seasonal_prices`
  - master data `addons`
  - master data `vouchers`
  - `bookings` list/create/show/adjustment
  - `payments` list/create
- Menambahkan dashboard yang memakai data nyata, bukan placeholder.
- Menambahkan filter dan search untuk halaman list utama.
- Menambahkan feature test untuk flow booking dan payment.
- Menambahkan seeder demo besar agar UI bisa langsung dipakai untuk eksplorasi dan testing manual.

## Perubahan Penting
- Money field project sudah diarahkan ke integer Rupiah.
- Input nominal di UI sudah diarahkan ke bilangan bulat tanpa `,00`.
- Dashboard sekarang menampilkan ringkasan nyata dari booking, payment, saldo tersisa, dan check-in mendatang.
- Seeder sekarang menghasilkan data master, booking, booking item, dan payment dalam jumlah yang cukup untuk operasional demo.

## Keputusan Final
- Database tetap MySQL.
- Tidak memakai PostgreSQL.
- UI dashboard wajib mengikuti TailAdmin yang sudah tersedia.
- Semua nominal disimpan sebagai integer Rupiah.
- Booking memakai `booking_items` untuk nightly pricing dan adjustment.
- Payment tetap dipisah dari booking total.
- Untuk booking, perubahan pasca-create dilakukan lewat adjustment, bukan edit bebas, agar histori transaksi lebih aman.
