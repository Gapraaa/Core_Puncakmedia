# Progress 2026-04-13

## Ringkasan
Fokus hari ini adalah pembenahan UI/UX besar-besaran (UX Refinements) pada modul operasional, mempercepat iterasi filter tabel, dan merombak total arus navigasi *Booking* untuk memberikan pengalaman manajemen properti yang berorientasi pada Villa (Villa-first experience).

## Selesai Hari Ini
- **Instant Client-Side Filtering (Realtime DOM Search)**
  - Mengimplementasikan pencarian data tanpa *refresh* / *loading* halaman pada semua daftar Master Data dan Operasional (Villas, Villa Units, Brands, Add-ons, Seasonal Prices, Vouchers, Bookings, Payments). Memanfaatkan JavaScript murni (vanilla `onkeyup`) untuk akurasi instan antar-halaman *paginasi* aktif.
  
- **UX Kalender Tanggal**
  - Mengonfigurasi seluruh elemen `<input type="date">` (Booking, Extend Checkout, Harga Musiman, dll) agar langsung membuka *native browser date picker* saat bidang teks diklik di bagian mana pun (`onclick="this.showPicker()"`).
  - Melakukan *data-binding* cerdas menggunakan `Alpine.js` agar pengguna tidak bisa memilih Tanggal Selesai yang posisinya mundur dari Tanggal Mulai (`:min`).

- **Perombakan Arsitektur Alur Booking (Villa-Centric Navigation)**
  - Menghapus entry point `bookings.index` lama yang menampilkan seluruh data secara acak.
  - Membangun Dasbor *Katalog Villa* khusus sebagai gerbang masuk pertama menu "Daftar Booking" yang terintegrasi penghitung *Total Reservasi* (*real-time*).
  - Mendelegasikan URL baru dengan pola *sub-domain route* `/bookings/villas/{villa_id}` untuk memisahkan ruang (scope) Booking secara tegas berbasis kepemilikan unit propertinya.
  - Menu *sidebar* dibersihkan dari *dropdown* pembuatan booking terpisah agar pemesanan selalu terekam berdasarkan properti Villa yang ditinjau admin saat itu (mengamankan *human error* input `villa_id`).
