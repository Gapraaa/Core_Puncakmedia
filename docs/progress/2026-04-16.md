# Progress 2026-04-16

## Ringkasan
Fokus hari ini adalah mengaktifkan sistem auth internal staff untuk Core PMS, mengganti halaman login TailAdmin menjadi alur login nyata berbahasa Indonesia, lalu mulai menerapkan pembatasan akses berbasis role sesuai dokumen produk.

## Selesai Hari Ini
- **Auth Internal Staff**
  - Menambahkan login session berbasis Laravel menggunakan `username + password` atau `email + password`.
  - Menambahkan logout yang membersihkan session dan token.
  - Semua route utama Core PMS sekarang diproteksi dengan middleware `auth`.
  - Guest yang membuka halaman dashboard / modul langsung diarahkan ke halaman masuk.

- **Role Middleware**
  - Menambahkan middleware `role` untuk membatasi akses route berdasarkan role user.
  - Role yang dipakai tetap mengikuti struktur dokumen:
    - `master`
    - `superadmin`
    - `head-office`
    - `finance`
    - `admin-sales`
  - Pembatasan awal sudah diterapkan ke area:
    - master data
    - booking
    - invoice
    - daftar pembayaran
    - laporan keuangan
    - pemetaan legacy

- **UI Login TailAdmin**
  - Tetap memakai halaman auth TailAdmin yang sudah ada.
  - Menghapus tombol login `Google` dan `X`.
  - Menghapus ajakan `Sign Up` publik.
  - Mengganti seluruh copy utama ke Bahasa Indonesia.
  - Menambahkan petunjuk akun demo internal (`master`, `finance`, `adminsales`).
  - Menghapus teks header tambahan di atas form login agar tampilan lebih bersih.

- **User Context di UI**
  - Dropdown user di header sekarang membaca user login asli.
  - Menampilkan nama user, username, role utama, dan tombol `Keluar`.
  - Sidebar sekarang difilter berdasarkan role agar menu yang tampil sesuai hak akses user.
  - Istilah UI utama dirapikan dari `Dasbor` menjadi `Dashboard`.

- **Manajemen User Internal**
  - Menambahkan modul `Manajemen User` khusus `master` dan `superadmin`.
  - User internal sekarang bisa dibuat, diedit, diberi role, dan dihapus dari dashboard.
  - Penghapusan akun yang sedang dipakai diblok agar tidak menghapus diri sendiri saat login.
  - Status user `aktif/nonaktif` sekarang bisa diatur dari form user.
  - Reset password internal dipusatkan di form edit user dengan pola: isi password baru jika ingin mengganti.

- **Flash Message Global**
  - Menambahkan flash message global berbasis komponen.
  - Notifikasi `success`, `error`, dan `warning` sekarang hilang otomatis setelah beberapa detik tanpa perlu refresh manual.
  - Alert sukses per halaman lama dibersihkan agar tidak muncul ganda.

- **Status User & Profil**
  - Menambahkan kolom `is_active` pada tabel `users`.
  - Login user nonaktif sekarang otomatis ditolak.
  - Route auth yang sudah login juga diproteksi dari user nonaktif aktif-sementara.
  - Halaman profil diubah agar benar-benar menampilkan user yang sedang login beserta role dan status akunnya.
  - User sekarang bisa mengubah nama, username, dan email sendiri dari halaman profil.
  - User sekarang bisa mengganti password sendiri dari halaman profil dengan validasi password lama.

- **Kalender Booking**
  - Placeholder kalender diganti menjadi modul kalender aktif.
  - Halaman kalender sekarang langsung menampilkan semua villa biasa dan semua unit resort dalam satu halaman.
  - Desain dibuat `Ctrl + F friendly` agar admin sales bisa cepat mencari nama villa, unit, brand, atau lokasi langsung dari browser.
  - Navigasi bulan sekarang berlaku per kartu kalender, jadi tiap villa / unit bisa digeser sendiri-sendiri.
  - Setiap kartu menampilkan mini kalender bulanan, ringkasan properti, jumlah booking, dan hari terisi.
  - Resort dipecah per unit agar visibilitas ketersediaan tetap akurat di level operasional.
  - Blok `Booking Bulan Ini` dihapus agar kartu lebih ringkas dan fokus ke kalender.
  - Layout kartu kalender diubah menjadi satu baris penuh per villa / unit agar lebih lega ke kanan.
  - Tanggal merah sekarang bisa diklik langsung ke detail booking terkait.

- **Audit Internal**
  - Field `created_by` saat create booking dan create pembayaran sekarang otomatis terisi dari user yang sedang login.
  - Menambahkan tabel dan modul `Audit Log` untuk merekam aktivitas penting user.
  - Aktivitas yang sudah tercatat meliputi:
    - login
    - logout
    - update profil
    - ganti password sendiri
    - create/update/delete user internal
    - create booking
    - create pembayaran
    - split invoice
    - penyesuaian booking
    - create/update/delete master data utama
  - Audit log dapat difilter berdasarkan user, modul, aksi, dan rentang tanggal.
  - Halaman audit log sekarang menampilkan detail perubahan `sebelum` dan `sesudah` langsung di tiap baris log.
  - Aktivitas pembukaan dan pengunduhan dokumen invoice / bukti pembayaran mulai direkam ke audit log.
  - Menambahkan tombol `Export CSV` pada modul audit log untuk kebutuhan rekap owner, finance, atau backup pengecekan manual.
