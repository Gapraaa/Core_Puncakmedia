# Progress 2026-04-22

## Ringkasan
Fokus hari ini adalah menyeragamkan standar waktu aplikasi ke zona waktu Indonesia WIB agar timestamp, tanggal operasional, nama dokumen, dan tampilan frontend tidak lagi mengikuti `UTC`.

## Selesai Hari Ini
- **Standar Waktu Aplikasi**
  - Konfigurasi timezone Laravel diubah menjadi berbasis env.
  - Menambahkan `APP_TIMEZONE=Asia/Jakarta` pada `.env`.
  - Default timezone aplikasi sekarang diarahkan ke `Asia/Jakarta` agar semua `now()`, `Carbon`, nama file dokumen, audit log, invoice, dan payment timestamp mengikuti WIB.

- **Bootstrap Timezone**
  - `AppServiceProvider` sekarang memaksa PHP runtime mengikuti timezone aplikasi saat boot.
  - Carbon locale tetap di-bootstrap dari config agar format tanggal terpusat dan siap dikembangkan lebih lanjut.

- **Frontend Date Rendering**
  - Formatter tanggal di `resources/js/app.js` dirapikan agar label tanggal frontend memakai locale Indonesia dengan timezone `Asia/Jakarta`.
  - Label preview booking dan label bulan pada kartu kalender sekarang mengacu ke WIB.
  - Penentuan indikator `hari ini` di kalender booking juga disesuaikan ke timezone WIB.

## Penyesuaian Dokumentasi
- `product/booking-flow.md` diperbarui dengan catatan bahwa standar waktu operasional Core PMS sekarang memakai WIB (`Asia/Jakarta`).
