# Progress Log

Folder ini dipakai untuk mencatat progres harian implementasi supaya keputusan, hasil kerja, dan next step tetap tertrack.

## Format yang dipakai
- 1 file per hari kerja
- Nama file menggunakan tanggal: `YYYY-MM-DD.md`
- Isi singkat dan fokus pada hasil, keputusan, risiko, dan next step
